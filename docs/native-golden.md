# Этап 2: контрольные нативные сборки на шести языках

`benchmarks/native_golden.py` создаёт независимые тестовые приложения для Java,
JavaScript, Python, Rust, Go и Ruby. До сборки записываются положительные и
отрицательные package URL. Используются javac/jar, npm pack/install, установка
локальных wheel через pip, cargo-auditable, go build и gem build/install.
Каждый язык содержит две поставленные версии, source-only зависимость и пакет,
удалённый отдельным слоем финального образа. Для Java/JS/Python/Ruby добавлена
metadata без кода; для Go/Rust — скопированные декларации без бинарника.

Все шесть положительных smoke-проверок прошли в контейнерах без сети, с read-only
файловой системой, без capabilities и с лимитами ресурсов. В production scanner
образы по-прежнему не запускаются. Не размеченные пакеты базового runtime не
участвуют в FP/FN; точность на всех зависимостях этими тестами не заявляется.

Исходное измерение правил v2: [baseline-v2](native-golden-baseline-v2.json).

| Язык | TP | FP | FN |
|---|---:|---:|---:|
| Java | 2 | 1 | 0 |
| JavaScript | 2 | 1 | 0 |
| Python | 2 | 1 | 0 |
| Rust | 2 | 0 | 0 |
| Go | 2 | 0 | 1 |
| Ruby | 2 | 1 | 0 |

Всего 13 положительных и 18 отрицательных идентичностей. Четыре FP — metadata-only
пакеты. Единственный FN — Go stdlib с различием префикса `go` в версии. Ни одна
из шести удалённых отдельным слоем зависимостей не вернулась в final.

Пилотный `native-golden-baseline.json` сохранён отдельно: в нём неверно задан
Go v2 tag без обязательного `/v2` module path. Исправлена сама тестовая сборка:
используются два допустимых релиза v1.0.0/v1.1.0. Ожидаемые версии не подменяются
версией, которую сообщил сканер. Пилот не является итоговой оценкой качества.

Следующий этап должен устранить обнаруженные FP/FN и сохранить положительные
контроли на тех же immutable образах. Базовые tags тестовых рецептов могут
изменяться при новой сборке; для сравнения используются сохранённые image IDs.

## Этап 3: проверка файлов пакета

Результат версии 0.3.0: [native-golden-release-v3.json](native-golden-release-v3.json).
Те же шесть immutable образов, те же ground-truth hashes: **13 TP, 0 FP, 0 FN**
на 13 положительных и 18 отрицательных метках. До изменения было 12 TP, 4 FP, 1 FN.

Syft теперь сохраняет metadata всех файлов конечной файловой системы. Для Python
проверяется наличие code-файла из RECORD, для npm/Ruby — payload в каталоге пакета,
для JAR — class-файл с class magic внутри архива, для Go/Rust — файл бинарника.
Чтение RECORD/JAR идёт из указанного Syft слоя сохранённого image archive, с лимитами,
без извлечения на диск и без запуска. Файл из удалённого слоя не подходит, если
его нет в конечном каталоге Syft. Npm-пакет не получает код вложенного пакета.

Go stdlib допускает только точное преобразование `go1.24.13` ↔ `1.24.13` для
`go-module-binary-cataloger`/`stdlib`; исходные version и PURL сохраняются в экспорте.
CI references остаются UNKNOWN с отдельной причиной `CI_CONFIGURATION`.

Неподдержанный формат, отсутствие RECORD, слишком большой JAR, ресурсы без class
или недостающий файл дают UNKNOWN, а не доказанное отсутствие. Наличие хотя бы
части payload не доказывает целостность всего пакета или исполнение его кода.
Старый replay без payload evidence явно отмечается `not_provided` и partial.
