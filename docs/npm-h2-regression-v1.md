## Новый контроль

До интеграции H2 выбраны Koa, Fastify, Hapi и получены только их HEAD commit
через git ls-remote. [Протокол](../benchmarks/npm-control-v2.json) фиксирует SHA,
правила оценки, ограничения и запрет замены неудобных/несобираемых проектов.
Их manifest, зависимости и результаты не читались в R7. Выбор по известным именам
серверных фреймворков, не случайная/репрезентативная выборка; общее знание проектов
не исключается. Зафиксированные в [отчёте](npm-h2-regression-v1.json) SHA256 H2,
matcher и протокола — граница заморозки перед просмотром новых проектов.

67 unit/regression tests прошли, Ruff, хеши входов/эталонов и схемы трёх SBOM
всех трёх прежних пар проверены. Новых сборок/сканов не было, performance/ресурсы
в этом этапе не измерены.

```powershell
python -m pytest benchmarks/test_npm_direct_h2.py benchmarks/test_npm_range_h2.py benchmarks/test_npm_direct_h1.py -q
python benchmarks/evaluate_npm_h2_regression.py
```
